# 获取授权码说明
用户在处理完证件照后保存或打印排版时需要输入授权码

# 授权码提示框说明
当用户处理完后需要保存或打印排版时检查是否需要获取授权码，如果需要获取授权码，则弹出一个输入授权码的提示框，提示框上需要说明"为了更好的用户体验，请输入授权码。输入框的旁边有个提示，没有授权码，点此获取"

# 操作流程
1.先调用check_need_auth_code方法检查是否需要授权码，如果需要打开浏览器到对应的获取页面
2.用户输入授权码后点击确定调用valid_auth_code方法，判断授权码是否正确。授权码正确则继续后面的操作
3.示例代码（详见example/get_auth_code_demo.py）
